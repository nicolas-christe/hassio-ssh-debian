# hassio-ssh-debian

Private Home Assistant add-on repository. Add via **Settings → Add-ons →
Add-on Store → ⋮ → Repositories** using this repo's URL, then install
**Linux Box**.

See [`REQUIREMENTS.md`](REQUIREMENTS.md) for the design/requirements doc,
and [`linuxbox/DOCS.md`](linuxbox/DOCS.md) for setup and usage.
